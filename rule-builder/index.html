How to write rules

Type comparisons the way you would say them. One rule per line is best. You can also paste a single sentence that uses combining with or extra ifs.

Examples

  • if current close > current open
  • if current high > previous high
  • if current upper wick < current lower wick
  • Bullish body: close greater than open
  • current body > 2
  • bullish candle
  • if current close > current open combining with if current high > previous high

Fields

  • Bars: current, previous (also prev, last, prior)
  • Prices: open, high, low, close, volume
  • Derived: upper wick, lower wick, body, range

Comparisons

  • > < >= <= = !=
  • Words: greater than, less than, above, below, at least, equal to

Combinations

If you write 3 rules, the tree contains every non-empty AND mix: 3 singles, 3 pairs, and 1 triple (7 total). Use min/max size to keep only pairs, only triples, and so on. Use “show at most n” to cap how many are drawn.
